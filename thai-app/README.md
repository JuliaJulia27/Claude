# Thai Tones — приложение для изучения тайского языка

PWA-приложение (веб-приложение, устанавливаемое на телефон) для изучения тайского языка
с переводом фраз с русского/французского и тренажёром тонов.

## Архитектурные решения (согласованы с пользователем)

| Вопрос | Решение |
|---|---|
| Объём работы | Полноценное приложение |
| Платформа | Веб-приложение / PWA (React + Vite, offline-first) |
| Обозначение тонов | Кривые/графики высоты тона над кириллической транскрипцией |
| Проверка произношения | Автоматический анализ высоты голоса через микрофон (Web Audio API) |

## Технологический стек

- **React 18 + TypeScript + Vite** — SPA, собирается в статические файлы
- **vite-plugin-pwa** — офлайн-кеш, манифест, "Установить на экран"
- **Tailwind CSS 4** — стили, мобильный layout с нижней навигацией
- **react-router-dom** (`HashRouter`) — маршрутизация, совместимая со статическим хостингом
- **Dexie.js (IndexedDB)** — локальное хранилище прогресса (SM-2 интервалы повторения, история попыток)
- **zustand + persist** — настройки пользователя (язык интерфейса) в localStorage
- **Web Speech API** (`speechSynthesis`) — озвучка тайских фраз (голос `th-TH`, если доступен в браузере)
- **Web Audio API** — захват микрофона + автокорреляционное определение основного тона (F0)
- Никакого backend: все данные (словарь, прогресс) хранятся и обрабатываются на устройстве

## Модель данных

`Phrase` = { категория, RU/FR перевод, тайское письмо, массив `Syllable` }.
`Syllable` = { тайское написание, кириллическая транскрипция, один из 5 тонов }.

5 тонов: **средний, низкий, нисходящий, высокий, восходящий** — у каждого своя
эталонная кривая (SVG) и эталонный контур высоты голоса (для сравнения с записью).

Стартовый словарь — 66 фраз в 10 категориях (приветствия, числа 0–10, базовые фразы,
еда, направления, покупки, экстренные ситуации, семья, время, тренировка тонов).
Тональная разметка построена по стандартным правилам тайской орфографии (класс
согласной + долгота гласной + тип конечного звука + тоновый знак) и общеизвестным
учебным примерам (классический набор ขา/ข่า/ค่า/ค้า/คา и скороговорка
ไม้ใหม่ไม่ไหม้ไหม). Перед ответственным использованием рекомендуется сверка с
носителем языка — структура данных рассчитана на лёгкое расширение.

## Тренажёр тонов — как это работает

1. `PitchRecorder` (`src/services/pitchDetector.ts`) захватывает микрофон через
   `getUserMedia`, кадр за кадром вычисляет частоту голоса методом автокорреляции
   (алгоритм ACF2+).
2. `normalizeContour` приводит запись к 10 точкам в диапазоне 0..1 (нормализация по
   длительности и высоте).
3. `scoreTone` (`src/services/toneScorer.ts`) сравнивает контур с 5 эталонными формами
   через корреляцию Пирсона, возвращает оценку 0–100% и распознанный тон.
4. Результат накладывается на эталонную кривую (`ToneCurveOverlay`) — пользователь
   видит, где именно голос отклонился от нужной формы.

## Перевод произвольных фраз — автоматический пайплайн

Экран «Перевод» не требует ручного выбора источника: если фразы нет в куррированном
словаре (или совпадение слабое), приложение само (с debounce 500 мс) обращается к
онлайн-переводчику и прогоняет результат через собственный модуль чтения тайского
письма — без выбора пользователя, единым результатом.

1. `src/services/onlineTranslate.ts` — переводит текст в тайское письмо. Пробует
   MyMemory (документированно поддерживает CORS из браузера) и неофициальный Google
   Translate как резерв, с таймаутом 6 с на провайдера, чтобы зависший запрос не
   блокировал пайплайн.
2. `src/services/thaiReading.ts` — **правило-ориентированный движок чтения тайского
   письма без словаря**: сегментирует произвольный тайский текст на слоги и для
   каждого определяет тон по классу начальной согласной (высокий/средний/низкий),
   долготе гласной, типу конечного звука (звонкий/глухой) и тоновому знаку —
   плюс кириллическая транскрипция. Обрабатывает кластеры согласных, дифтонги,
   немую ведущую ห/อ (ห-นำ) и "тхантхакхат" (่ ์, гасящий знак). На валидационном
   прогоне по всем 66 фразам куррированного словаря совпадает с проверенной вручную
   разметкой в 63/67 случаев (94%) — оставшиеся 4 расхождения относятся к
   нерегулярным словам с "скрытыми" гласными (заимствования из санскрита/пали,
   например สวัสดี, ตำรวจ), которые лексически не выводятся из одних правил
   орфографии — они уже есть в куррированном словаре, так что автоматический путь
   их не затрагивает.

Куррированные записи (тон сверен вручную) всегда в приоритете; автоматический режим
подключается только для остального — с пометкой в интерфейсе, что разметка
алгоритмическая и не проверена человеком.

## Экраны приложения

- **Главная** — карточка "к повторению сегодня" (SRS) + быстрые ссылки
- **Перевод** — RU/FR → тайский; словарь + автоматический перевод/транскрипция для
  всего остального; голосовой ввод (Web Speech API); отдельный перевод по словам для
  фраз из нескольких слов; переключатель ♂/♀ добавляет вежливую частицу ครับ/ค่ะ/คะ
  в конец фразы
- **Разговорник** — фразы по категориям
- **Уроки** — модули по темам + отдельный модуль теории тонов
- **Упражнения** — флеш-карточки (SM-2), тест с вариантами, упражнение на слух
- **Тренажёр тонов** — запись голоса и сравнение с эталоном
- **Прогресс** — точность по каждому из 5 тонов, статистика повторений
- **Настройки** — язык интерфейса (RU/FR), пол говорящего (для частиц ครับ/ค่ะ),
  экспорт/импорт данных (JSON)

## Разработка

```bash
cd thai-app
npm install
npm run dev       # разработка
npm run build      # прод-сборка (dist/)
npm run preview    # локальный просмотр собранной сборки
```

Приложение полностью офлайн-совместимо после первой загрузки (service worker кеширует
статику и данные). Для установки на телефон достаточно открыть сайт в браузере и
выбрать «Добавить на экран «Домой»» — публикация в App Store/Google Play не требуется.

## Возможные направления развития

- Расширение куррированного словаря (сейчас 66 фраз с ручной проверкой)
- Уточнение движка чтения тайского письма на нерегулярных/заимствованных словах
  (потребует небольшой словарь исключений)
- Предзаписанное аудио носителя языка вместо/в дополнение к TTS
- Синхронизация прогресса между устройствами (потребует backend)
