# Claude

Ce dépôt regroupe plusieurs applications indépendantes, chacune dans son
propre dossier avec son propre README détaillé.

## Applications

- **[divia-app](./divia-app)** — Horaires en temps réel des trams et bus du
  réseau DiviaMobilités à Dijon : choix de la ligne, de l'arrêt et de la
  direction.
- **[thai-app](./thai-app)** — Application d'apprentissage du thaï (Thai
  Tones) : traduction RU/FR ↔ thaï et entraîneur de tons par analyse vocale.

Chaque application est un projet React + Vite + TypeScript autonome ; voir
son README pour les instructions de développement et les décisions
d'architecture propres à ce projet.
